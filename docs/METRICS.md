# 七项指标与迁移说明

这里描述软件实际实现，不代表已经通过特定论文、实验室标准或人工标注的科学准确性认证。

## 输入与标定

掩码内部 `255` 代表染色，导出时黑色 `0` 代表染色。所有指标使用同一张无标线二值掩码。二值输入用灰度 ≤127 判为染色；HSV 输入以所选范围为染色。

设图像宽高为 W、H 像素，真实剖面宽高为 L、D cm，染色像素数为 N，每行染色比例为 r(y)。

- 单像素面积：`L × D / (W × H)` cm²。
- 单行高度：`D / H` cm。
- 起始深度使用 cm，换算为起始行后寻找基质流边界。

## 定义

| 指标 | 实现 |
| --- | --- |
| 染色面积 | `N × L × D / (W × H)` |
| 染色面积比 | `100 × N / (W × H)` |
| 基质流深度 | 起始深度后首个 `r(y) ≤ matrix_threshold` 的行号乘单行高度；没有此行则为整个剖面高度 |
| 优先流百分数 | 基质流边界以下实际染色像素数 / 全部染色像素数 ×100 |
| 优先染色面积比 | 基质流边界以下实际染色像素数 / 全部像素数 ×100 |
| 最大染色深度 | `r(y) ≥ depth_threshold` 的最深一行下边界的物理深度 |
| 长度指数 | `100 × Σ abs(r(y) − r(y−1))` |

默认基质阈值 0.8、最大深度阈值 0.005。长度指数可以超过 100，不是百分比。全空白图七项指标均为零；全染色图的基质流深度和最大深度等于整个剖面高度，优先流百分数为零。

## 相对旧代码的修正

旧版固定按 10 px/cm 计算，且优先面积使用 `染色面积 − 宽度 × 基质深度`，这会在宽度、分辨率变化或基质区未完全染色时产生不一致甚至负数。新版按真实宽高标定，并直接数基质边界以下的染色像素。因此新版结果不保证逐值复现旧版。

旧版最大深度使用稀疏行累计及整数取整，可能把不相邻的两行作为停止条件。新版使用明确阈值的最深有效行。

调整分辨率仍可能改变边界附近的分割像素；尺度不变测试针对相同形状的理想掩码，不能保证任意照片在不同重采样尺寸下数值完全相同。

自动识别仅在 ≥98% 像素满足 RGB 通道差≤2 且接近黑（≤20）或白（≥235）时选择二值模式，其他图片选择 HSV，避免单凭暗色比例判断。

K-means 在 HSV 空间使用固定随机种子、最多 20000 个拟合样本。两种模糊模式分别归类并统计。颜色面积包含白色背景，不应将每类面积都理解为染色面积。
